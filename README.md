# 🐠 Clownfish Behaviour Simulation - Unity

📚 Dissertation Context

This project was developed as part of my **Master’s dissertation at the University of Sheffield**, where it received a **Distinction**.
The research aimed to bridge computational modeling with biological realism to create engaging educational simulations.

A first-of-its-kind **virtual aquarium** built in **Unity** that simulates realistic **clownfish behaviour** using **state machines** and **agent-based modeling**.  
The project balances **scientific accuracy** with **user engagement**, making it a tool for **education, marine biodiversity awareness, and conservation efforts**.  

---

## 🎯 Project Overview
This simulation models the daily life of clownfish in a dynamic environment.  
It captures individual and group behaviours by responding to environmental stimuli such as territory, threats, and social hierarchy.

Key simulated behaviours:
- 🏊 **Passive Swimming** – natural free-roaming movement.
- ⚔️ **Aggression** – defending territory against intruders.
- 🏃 **Retreat** – avoidance when threatened.
- 👑 **Hierarchy Adaptation** – dominance and submission dynamics.
- 🐟 **Reproduction** – spawning and lifecycle behaviours.

---

## 🛠️ Tech Stack
- **Engine:** Unity  
- **Language:** C#  
- **Modeling Approach:** State Machine + Agent-Based Modeling  
- **Environment:** Interactive 3D Aquarium  

---

## 🚀 Features
- Interactive aquarium where users can observe clownfish behaviour in real-time.  
- Scientifically informed models of clownfish hierarchy and aggression patterns.  
- Modular state-machine design for extensibility (e.g., adding new fish species).  
- Educational focus on marine ecosystems and conservation awareness.
